# Letter Recognition Analysis

## Dataset
- 20,000 samples, 16 numerical features, 26 letter classes (A–Z).
- Goal: Explore, cluster, reduce dimensions, and classify handwritten letters.

## Techniques
- **EDA:** Examine dataset structure, class distribution, and feature statistics.
- **Preprocessing:** Handle missing values, outliers, scaling, and normalisation.
- **K-Means:** Perform clustering and use the Elbow Method to select K.
- **DBSCAN:** Identify density-based clusters and noise points.
- **PCA:** Reduce 16 features to 2 principal components for visualisation.
- **Model Evaluation:** Evaluate KNN using 5-fold Stratified Cross-Validation.

## Libraries
- NumPy
- Pandas
- Matplotlib

## How to Run
- Keep the notebook and CSV file in the same directory.
- Install the required libraries.
- Open the notebook in Jupyter Notebook or Google Colab.
- Run all cells sequentially.
